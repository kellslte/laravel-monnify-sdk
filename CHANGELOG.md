# Changelog

All notable changes to this project are documented in this file.

## [1.2.0] - 2026-04-19

### Added

- Support for Laravel 13 (`laravel/framework ^13.0`). Applications on Laravel 13 require PHP 8.3 or higher (enforced by the framework).

### Changed

- Development dependency `orchestra/testbench` now allows `^11.0` for Laravel 13 package tests.
